# 演示视频录制清单（3~5 分钟）

> 用途：复试素材，B 站发布。每完成一个模块按此清单录一条，录制前先看一遍"通用规范"。

## 通用规范

- [ ] 分辨率 1080p、30fps（OBS 录制，录像前先录 10 秒测试片段检查声音）
- [ ] 系统通知/弹窗全部关掉，避免录进画面
- [ ] 终端字号调大（>= 16pt），命令清晰可读
- [ ] 开头 3 秒亮出项目名 + 日期（可加字幕）
- [ ] 全程有解说（提前写稿，照着念即可）
- [ ] 录完导出时加字幕（B 站自动字幕校对一遍也行）
- [ ] 文件名规范：`uuv_navi_建图导航_v1.mp4`（v1/v2 递增，别覆盖）
- [ ] 封面：RViz 粒子云收敛 + 路径规划的截图

## 分镜脚本（以"建图 + 导航"为例）

### 00:00 ~ 00:15 开场

- 画面：仓库 README 或项目架构图
- 解说："大家好，这是 uuv_navi 项目——先车后船，把无人系统的建图、定位、规划、控制闭环先在小车上跑通。今天演示的是第一环：Gazebo 里的 SLAM 建图和自主导航。"

### 00:15 ~ 00:40 环境展示

- 画面：终端执行 `roslaunch turtlebot3_gazebo turtlebot3_world.launch`，Gazebo 窗口出现小车
- 解说：环境是 ROS1 Noetic + Gazebo 11，车型 waffle_pi，带 360 度激光。三个终端分别负责仿真、建图、遥控。

### 00:40 ~ 02:00 建图

- 画面：三个终端同屏（可用 tmux 分屏）：仿真 / gmapping（RViz 地图生长）/ 键盘遥控
- 解说：按住 w 让车慢慢绕房间一圈，RViz 里栅格地图实时生长；讲解 log-odds 栅格 + 扫描匹配一句带过
- 可选彩蛋：录一段"松开键盘车不停"的片段，解说这是仿真没有速度看门狗导致的，按 s 停车——展示真实踩坑过程
- 收尾：`rosrun map_server map_saver -f ~/uuv_navi/maps/map`，展示生成的 map.yaml + map.pgm

### 02:00 ~ 03:30 导航

- 画面：新终端启动 navigation launch；RViz 出现地图和车
- 重点画面（各 3~5 秒）：
  - 2D Pose Estimate 设初始位姿（**一定要展示拖方向的动作**）
  - 粒子云从散开 → 收敛聚团
  - 激光轮廓和地图墙线重合的瞬间
  - 2D Nav Goal 发目标 → 绿色全局路径 → 小车转弯/绕障 → 到达自动停
- 解说：AMCL 粒子滤波定位，move_base 全局+局部规划；初始位姿不能省，它是整个定位的种子

### 03:30 ~ 03:50 总结

- 画面：回到 README/下一步计划
- 解说：下一步会换成自己搭的 Gazebo 环境重跑，再把这套迁移到 ROS2 和集群编队。感谢观看。
